Goal

ReadAloud keeps its current playback engine, cache and fallback chain. VoiceStudio becomes the cloud provider behind the existing /api/tts contract, so the browser never talks to it directly and never holds its key.

In scope

  • Run VoiceStudio locally in Docker on the CPU, with KittenTTS as the first engine.
  • A proxy that adds the API key and satisfies VoiceStudio's origin and host checks.
  • A provider adapter for its OpenAI-style speech endpoint.
  • Voices listed from the server instead of the hard-coded eight.
  • Tests that run without VoiceStudio, plus a tagged live suite.

Not in scope

  • Voice cloning UI. The server's own app covers it; ReadAloud only lists resulting profiles.
  • Dubbing, transcription, dictation and the mobile apps.
  • GPU engines. OmniVoice wants about 6 GB of graphics memory and its weights are non-commercial.
  • Forking VoiceStudio. Calling it over HTTP keeps ReadAloud's licence independent of its AGPL terms.

Why this shape

The adapter is small because ReadAloud already synthesizes one sentence per request, prefetches two ahead and caches audio in IndexedDB. The only missing piece on the server side is word timings, which stay estimated unless phase 4 ships.

Language coverage by engine

All four run on the CPU. KittenTTS is the recommended first engine: English only, but the smallest install and real-time on any CPU according to its guide.

What VoiceStudio gives us, and what it doesn't

NeedVoiceStudioPlan
Per-sentence MP3YesPOST /v1/audio/speech, up to 4096 characters, formats mp3, opus, wav, pcm.
Voice listYesGET /profiles for cloned voices plus engine preset names.
Word timingsNoSpeech endpoint is audio only. Phase 4 derives timings from the transcription endpoint.
Browser callsGatedNeeds bearer key, listed origin and known host. Proxy handles all three.
StreamingYesChunked audio or a WebSocket. Not needed: sentences are short and prefetched.
Speed controlServer-sideAlways request 1×. The audio element's playback rate handles speed, so cached clips work at any speed.
