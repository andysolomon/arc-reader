The private AWS target reuses the same Kubernetes module on EC2 with k3s and keeps VoiceStudio on the Mac mini. C4 model · architecture

Three levels of zoom

Level 1: who uses ReadAloud and which outside systems it depends on. Speech normally comes from the Mac mini.

Level 2: what runs where on Omarchy. Only the web pod is on the request path; the control plane recreates it on each deploy.

Level 3: the server plugins inside the web pod. The preparation queue yields to live listening so the Mac's single GPU worker never refuses a listener.

Terraform · deployment ownership

Two stages per target, one app module

kind state: ~/.local/state/readaloud/terraform. AWS state: ~/.local/state/readaloud/aws. State is shared across worktrees and contains secrets. The old Kubernetes YAML files have been replaced by Terraform.

The Omarchy kind cluster completed its Terraform cutover on 6 Nov 2026 with the original Docker volumes preserved. Other unmanaged clusters still need a backup and the one-time rebuild described in the README. Later deploys do not automatically recreate a running cluster.

Deployment · AWS target · not provisioned

The web app on EC2; speech stays on the Mac

Expected URL after provisioning: https://readaloud-aws.tail1b9428.ts.net. Tailscale Serve proxies to 127.0.0.1:30179. The security group admits UDP 41641 for Tailscale; there is no public HTTP, SSH or Kubernetes API ingress. Tailnet policy controls access to the app and API.

ECR supplies the amd64 web image using the instance role. SSM retrieves the admin kubeconfig; the Kubernetes API is reached over the tailnet on TCP 6443. CoreDNS forwards the tailnet zone to Tailscale. AWS has no local VoiceStudio fallback unless a second remote URL is explicitly configured.

The EBS disk holds library, preparations, k3s state and Tailscale identity. Seven daily snapshots are retained. The disposable root disk is 30 GB. AWS starts with an empty library; local Docker volumes are not uploaded. Snapshot copies must not run alongside the original with duplicate identities.

Vercel remains future work: the complete app still needs durable storage, a durable preparation worker, function routes, and a network path to private VoiceStudio. See the README for setup, credentials, cutover and recovery.
